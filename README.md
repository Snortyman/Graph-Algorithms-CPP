# GraphProject
Учебный проект по структуре данных Граф  на языке C++, реализующий базовые алгоритмы обхода и анализа связности.

Возможности программы
* Список смежности (`std::vector<std::list<int>>`): Эффективное хранение графа в памяти.
* Управление вершинами и ребрами: Добавление и удаление ребер, а также добавление и удаление вершин.
* Обходы графа:
  * Поиск в ширину (BFS — Breadth-First Search) с использованием `std::queue`.
  * Поиск в глубину (DFS — Depth-First Search) с использованием `std::stack`.
* Проверка связности: Алгоритм проверки, является ли граф связным.
* Чтение из файла: Загрузка структуры графа из текстового файла `input.txt`.

Используемые технологии
* Язык: C++ (стандарты C++11 и выше)
* Библиотеки STL: `<vector>`, `<list>`, `<queue>`, `<stack>`, `<fstream>`, `<iostream>`

Структура проекта
* `Main.cpp` — основной файл с реализацией класса `Graph` и демонстрацией его работы.
* `input.txt` — файл с входными данными для инициализации графа.
